Sistema de coordenadas de origem

A interface identifica o sistema de referência a partir do arquivo .prj e atribui coordenadas em graus, sendo sugerido o sistema de referência SIRGAS 2000. De todo modo, verifique qual o sistema de referência nativo da feição. A conversão para SIRGAS 2000 / Polyconic acontece no banco.
